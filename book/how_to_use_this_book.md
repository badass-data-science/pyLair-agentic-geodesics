# How to Use This Book

**Who this book assumes you are.** Comfortable with basic 3D coordinate geometry — vertices, planes, angles — and command-line tools. New to geodesic subdivision specifically, new to 2D nesting specifically, and new to agentic tool-use generally. Nothing past that is assumed; Chapter 1 starts from what "agentic AI" even means, and Chapter 3 starts from what a polyhedron is doing in a geodesic dome in the first place.

**The prompt-based convention used throughout.** Every worked example in this book shows a boxed **Prompt** (what you'd actually type to your agent), followed by **What Comes Back** (the tool's real JSON or CLI output, trimmed for space where it runs long), followed by **What It Means** (the plain-language interpretation). This convention runs from Chapter 2's first smoke test straight through Chapter 24's closing summary, across both toolkits.

**Every number in this book is real.** Every vertex count, error message, image, and file this book shows you came from an actual `pylair`/`pylair-mcp`/`pyfit`/`pyfit-mcp` run against real parameters — not a hand-typed mockup. Where a chapter shows you a CLI command, that command is the exact one that produced the result shown next to it; installing both toolkits (Chapter 2) and running that same command yourself will get you the same numbers, not an approximation of them. Where this book found something surprising during its own drafting — a formula that didn't behave the way an earlier draft assumed, a real bug reproduced live, a result that came back the opposite of expected — it says so plainly rather than smoothing the surprise away.

**A note on this book's images.** This book is illustration-heavy on purpose: every subdivision class, every shaping operation, and every nesting concept gets at least one real figure, because geodesic geometry and 2D nesting are both subjects far easier to *see* than to read a paragraph about. Every image in this book is one of three things, and its caption says which: a real render from pyLair's own `-P/--preview` (or pyFit's own equivalent); a real DXF-derived or report-derived figure built directly from a tool's actual output data; or a small number of purpose-drawn conceptual diagrams — a bare symmetry triangle before it's replicated, a chiral mirror-pair comparison, a no-fit-polygon construction — built from the same real coordinate data the surrounding prose is discussing, not illustrated freehand. None of this book's images were generated by an image-generation model; every one is either a real tool output or a diagram plotted directly from real, computed numbers.

**Pointers for going deeper.** Each project's own `README.md` is the complete, current CLI/MCP reference and caveats list; each project's own `AGENTS.md` is its engineering notes, including footguns this book's own chapters walk through in narrative form. Where this book's own drafting surfaced something worth a project's maintainers knowing about — a real edge case, a genuinely surprising result — the relevant chapter says so explicitly, but this book itself doesn't modify either project; it teaches what already exists.
