# About the Author

Emily Williams is a data scientist by day, a DJ by night, and 100% up to no good! When she isn't forecasting death-ray rental revenue two volumes over, she's out here computing hub angles for a geodesic secret lair — and, wisely, letting an actual geometry engine check her arithmetic before any henchman gets handed a strut that's the wrong length.

She maintains that "agentic AI" and "a suspiciously well-organized supervillain operation" run on the same underlying principle: never let anyone — human, henchman, or LLM — freehand something a deterministic function can just compute correctly the first time.
